# Отчёт об эксперименте

## Данные

- Файл для обучения: `data/wines_annotated.csv`.
- Загружено: 3 036 строк с частичной LLM-разметкой.
- После удаления повторных модельных текстов: 3 030 объектов.
- Основное описание отсутствует у 874 строк; в таких случаях текст дополняется названием и рекомендацией по употреблению.
- Каждая модель использует все доступные для неё метки. После очистки доступно:
    - 770 меток для кислотности;
    - 1 518 меток для танинности;
    - 409 меток для тела;
    - 1 269 меток для интенсивности.


## Протокол

- Случайное hold-out-разделение 75/25, `random_state=42`.
- Векторизация: `char_wb` TF–IDF, n-граммы 3–5, максимум 30 000 признаков.
- Классификатор: логистическая регрессия с `class_weight="balanced"`.
- Для мультиметок используются независимые бинарные классификаторы и порог 0.35.
- Общее разбиение объектов фиксировано для всех целей; внутри train и test каждая модель берёт только строки со своей меткой.
- После оценки каждая финальная модель переобучается на всех доступных для неё метках.

## Результаты hold-out

Сравнение трёх представлений текста на одном разбиении:

| Вариант | Средний macro-F1 категорий | Aroma micro-F1 | Taste micro-F1 |
|---|---:|---:|---:|
| Символьный TF–IDF 3–5 | 0.781 | 0.517 | 0.437 |
| Словный TF–IDF 1–2 | 0.740 | 0.471 | 0.408 |
| Гибрид символы + слова | **0.792** | **0.603** | **0.526** |

Полные результаты и время запуска сохранены в `artifacts/experiment_comparison.csv`; воспроизводящий код находится в `experiments/compare_vectorizers.py`.

Таблица сравнения выше относится к предыдущему weak-supervision эксперименту. Ниже приведена детализация символьного baseline, сохранённого в текущем API bundle.

## Интерпретация

Эти значения измеряют способность модели воспроизводить LLM-псевдоразметку. Они **не оценивают качество относительно мнения эксперта**. Особенно осторожно следует интерпретировать редкие классы, например высокую танинность.

Следующий валидный эксперимент должен использовать ручную разметку, group split по товару/бренду, отдельные validation и test-наборы, подбор порогов только на validation и сравнение TF–IDF baseline с русскоязычной transformer-моделью.
