# План тестирования

Автоматизированные тесты в `tests/` проверяют:

- нормализацию текста и загрузку model bundle;
- наличие всех шести групп целей в прогнозе;
- отказ на пустом описании;
- `/health` и `/model/info`;
- контракт одиночного и пакетного прогнозов;
- валидацию слишком короткого текста;
- публикацию технических метрик.

Запуск: `pytest`.

Перед production дополнительно нужны нагрузочный тест целевой RPS, тест несовместимого/повреждённого bundle, security-проверки образа и зависимостей, тест русского Unicode и граничных 20 000 символов, а после ручной разметки — regression-набор с фиксированными ожидаемыми метриками.
