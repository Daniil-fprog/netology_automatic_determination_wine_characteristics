# Контракт API

После запуска интерактивная спецификация OpenAPI доступна по `/docs`, исходная схема — по `/openapi.json`.

## Методы

### `GET /health`

Возвращает `200`, если артефакт модели успешно загружен. При недоступной модели возвращает `503`.

### `GET /model/info`

Возвращает режим модели, число обучающих объектов, список целей и метаданные bundle.

### `POST /predict`

Запрос:

```json
{
  "description": "Красное вино с ароматом вишни и пряностей, плотным вкусом и мягкими танинами."
}
```

Ответ:

```json
{
  "categories": {
    "acidity_level": {"label": "средняя", "confidence": 0.81},
    "tannin_level": {"label": "средняя", "confidence": 0.76},
    "body_level": {"label": "полное", "confidence": 0.73},
    "intensity_level": {"label": "высокая", "confidence": 0.84}
  },
  "aroma_notes": [{"label": "красные ягоды", "probability": 0.71}],
  "taste_notes": [{"label": "пряности", "probability": 0.61}],
  "model_mode": "supervised"
}
```

Описание должно содержать 10–20 000 символов. Ошибка валидации возвращает `422`; отсутствие модели — `503`.

### `POST /predict/batch`

Принимает `{"descriptions": [...]}` от 1 до 100 описаний и возвращает массив `predictions` в исходном порядке.

### `GET /metrics`

Технический endpoint в текстовом Prometheus-формате: количество запросов, ошибок, прогнозов, суммарная задержка и факт загрузки модели.
