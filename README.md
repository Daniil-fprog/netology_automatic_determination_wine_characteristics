# Автоматическое определение характеристик вина

Проект машинного обучения для определения по текстовому описанию вина:

- кислотности, танинности, плотности и интенсивности вкуса;
- ароматических и вкусовых нот (мультиметочная классификация).

## Ноутбуки

- `notebooks/01_wine_characteristics_project.ipynb` — аудит и EDA, подготовка данных, обучение, оценка, анализ ошибок и сохранение модели.
- `notebooks/02_model_inference.ipynb` — загрузка сохранённой модели и предсказание для нового описания.

Оба ноутбука уже выполнены и содержат сохранённые выводы. Для повторного запуска сначала выполните первый, затем второй.

Основные зависимости: Python 3.11, pandas, numpy, scikit-learn, matplotlib, seaborn и joblib.

## Артефакты

После выполнения первого ноутбука в `artifacts/` создаются:

- `wine_characteristics_model.joblib` — векторизатор, классификаторы, кодировщики и метаданные;
- `categorical_metrics.csv` и `multilabel_metrics.csv` — итоговые метрики;
- `test_predictions.csv` — предсказания на тестовой части для анализа ошибок.

## Состояние исходных данных

Файл `data/wines.csv`, находящийся в текущей рабочей копии, содержит 42 строки. Все целевые столбцы в нём пусты, хотя в постановке заявлено около 3 000 размеченных описаний. Поэтому ноутбук автоматически включил явно обозначенный демонстрационный режим слабой разметки. Его метрики нельзя считать production-оценкой.

Если заменить CSV на размеченную версию с целями `acidity_level`, `tannin_level`, `body_level`, `intensity_level` (также поддерживается исходный алиас `taste_intensity`), `aroma_notes` и `taste_notes`, основной ноутбук автоматически перейдёт в обычный supervised-режим.
